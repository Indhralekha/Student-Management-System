
# Student Management System

## Project Overview
The Student Management System is a full-stack web application designed to manage student information efficiently. It allows users to add, view, update, and delete student records.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Java
- Spring Boot
- Spring Web

### Database
- MySQL

### Development Tools
- Visual Studio Code
- Git
- GitHub
- Maven

## Features
- Add new student details
- View all student records
- Search students by ID
- Update student information
- Delete student records
- REST API integration

## How to Run

### Backend
1. Open the backend folder.
2. Run the Spring Boot application using Maven.
3. Backend runs on port 8080 (if configured).

### Frontend
1. Open the React application folder containing package.json.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL displayed in the terminal.

## Project Objective
To simplify student record management through a user-friendly web application with a React frontend, Java Spring Boot backend, and MySQL database.
